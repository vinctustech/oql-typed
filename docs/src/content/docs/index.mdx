## Why oql-typed

<CardGrid>
  <Card title="Typed projections" icon="approve-check">
    `.select('id', { account: ['id', 'name'] })` produces a precisely typed result — no manual type parameter, no casts.
  </Card>
  <Card title="Typed filters" icon="approve-check">
    `eq`, `ilike`, `inList`, `exists`, etc. validate field types at compile time. `eq(user.enabled, 'yes')` is a type error.
  </Card>
  <Card title="Schema as source of truth" icon="document">
    Declare entities once in TypeScript. The OQL data model is derived from them, so there is no second copy to keep in sync.
  </Card>
  <Card title="One dependency" icon="setting">
    `createPostgresDB(schema, connection)` builds the PostgreSQL backend for you; `createPetraDB(schema)` runs the same schema in memory for tests.
  </Card>
</CardGrid>
