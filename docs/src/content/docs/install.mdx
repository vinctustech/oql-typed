## Library

<Tabs syncKey="pkg">
  <TabItem label="npm">
    ```bash
    npm install @vinctus/oql-typed
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add @vinctus/oql-typed
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @vinctus/oql-typed
    ```
  </TabItem>
</Tabs>

That's the whole install. The PostgreSQL driver (`@vinctus/oql-pg`) comes along as a dependency, and the schema you declare in TypeScript is the only data model.

## Pick a backend

<Tabs>
  <TabItem label="PostgreSQL (production)">
    Nothing else to install.

    ```typescript
    import { createPostgresDB } from '@vinctus/oql-typed'
    import { schema } from './schema.js'

    export const db = createPostgresDB(schema, {
      host: 'localhost',
      port: 5432,
      database: 'mydb',
      user: 'user',
      password: 'pass',
    })
    ```
  </TabItem>
  <TabItem label="In-memory (tests)">
    The in-memory backend is an optional peer — install it only if you use it.

    ```bash
    npm install --save-dev @vinctus/oql-petradb
    ```

    ```typescript
    import { createPetraDB } from '@vinctus/oql-typed'
    import { schema } from './schema.js'

    export const db = createPetraDB(schema)
    // no external database needed — perfect for unit tests
    ```
  </TabItem>
</Tabs>

## Requirements

- **Node.js** ≥ 20
- **TypeScript** ≥ 5.4 — uses `NoInfer<T>` to pin operator value types to the field type
- **ESM** — set `"type": "module"` in your `package.json`

<Aside type="tip">
You can mix the two backends: run production on PostgreSQL with `createPostgresDB` and your test suite on `createPetraDB`. The same schema definition drives both.
</Aside>
